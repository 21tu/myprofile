# コードレビュー基準・チェックリスト

## レビュー記録
- PR: 
- Reviewer / Date:
- 対応仕様ID:
- 判定: APPROVE / REQUEST_CHANGES / COMMENT
- 未解決リスク:

## ブロッカー（P0）
- [ ] 仕様IDと変更内容・テストが対応している
- [ ] TypeScript strict / lint / format / tests / build が成功
- [ ] 静的エクスポートとCloudflare配信に矛盾がない
- [ ] 秘密情報がGit・ビルド成果物・ログに含まれない
- [ ] XSSを招く危険なHTML・外部スクリプトを導入していない
- [ ] 本番のHTTPS・CSP・セキュリティヘッダーを検証した
- [ ] キーボードで主要操作が可能でフォーカスが視認できる
- [ ] reduced-motionが機能し、コンテンツ閲覧を妨げない
- [ ] 320px幅からレイアウトが破綻しない
- [ ] 架空の経歴・実績・連絡先が本番にない

## 設計・保守性
- [ ] 単一責任で読みやすく、God Componentがない
- [ ] 不要なuseEffect / use client / state / memo化がない
- [ ] any / ts-ignore / 型アサーションに正当な理由がある
- [ ] 依存方向が明確で循環依存がない
- [ ] 過剰な抽象化、未使用依存、コピペ重複がない
- [ ] 命名・エラーハンドリング・テストが適切

## UI / UX / 性能
- [ ] CTAが明確、リンク先が正しい
- [ ] セマンティックHTML、代替テキスト、見出し階層が適切
- [ ] 色コントラスト・タップ領域・タッチ操作を確認
- [ ] アニメーションが操作・読解・性能を妨げない
- [ ] 画像の容量・サイズ指定・遅延読込を適切に設定
- [ ] Lighthouse/実機結果を記録した（測定できない場合は未検証と明記）

## セキュリティ・運用
- [ ] 依存監査の重大・高リスク問題を評価した
- [ ] 権限は最小化され、デプロイに承認が必要
- [ ] CSP緩和の理由と影響が記録されている
- [ ] ログ・アクセス解析・個人情報の取扱いが明確

## レビューコメント形式
`[SEVERITY: BLOCKER|MAJOR|MINOR] [SPEC-ID] file:line — 問題 / 影響 / 推奨修正 / 検証方法`

## 判定基準
- BLOCKER: 秘密情報漏えい、実害のあるセキュリティ欠陥、ビルド不能、P0未達 → マージ不可
- MAJOR: 重大なUX/性能/保守性問題、P1未達 → 原則修正または承認済み例外
- MINOR: 可読性や軽微な改善 → 修正推奨
- 自動検査の成功だけでWCAG/ASVS完全準拠を宣言しない
